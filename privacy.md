SigningRoom.io operates as an end-to-end encrypted, operator-blind relay and does not collect personal account information, set tracking cookies, or maintain user accounts. Application-level request invocation logging is disabled (`invocation_logs: false`).

During an active signing ceremony (up to the 24-hour room TTL), encrypted session ciphertext is held in ephemeral Cloudflare Durable Object storage solely to synchronize connected peers and is permanently purged via `storage.deleteAll()` immediately upon room closure or TTL expiration (retaining only a 28-byte timestamp tombstone for 1 hour to prevent closed room ID re-initialization before final deletion). Self-hosted `workerd` deployments operate in volatile memory (`inMemory = void`).

Transient network metadata (such as client IP addresses) is processed in memory strictly for rate-limiting and abuse prevention, with Cloudflare acting as edge sub-processor for hosted deployments.

**Optional Local Address Book (Client-Side Only):** By default, signer and address labels exist only within the encrypted, ephemeral room state and vanish upon room closure or expiration. Coordinators may optionally opt in ("Save to local Address Book") to cache hardware fingerprint or UTXO address labels locally on their browser. When enabled, entries default to **Tab Only** (`sessionStorage`, automatically wiped when the browser tab closes) or can be set to a **1-, 7-, or 30-day TTL** in `localStorage` (proactively purged on application startup after expiration, or wiped immediately by unchecking the option). This data remains strictly on the user's local device unless applied to a room.
